# Merchant Action Agent

A multimodal, human-in-the-loop AI agent for small business automation.

**Meta Global AI Developer Hackathon 2026**

## The Problem

Small business owners often spend time managing product catalogs, promotions, and customer communications through multiple interfaces.

## Our Solution

Merchant Action Agent transforms product images and natural-language or voice instructions into structured business actions.

For example, a merchant can upload product photos and request:

"Add these bags to my catalog at 850 TRY each, prepare a 15% weekend discount, and draft a campaign for returning customers."

The agent will:
1. Analyze the provided media and instructions.
2. Extract product information.
3. Generate catalog and campaign proposals.
4. Validate requested actions.
5. Request explicit human approval.
6. Execute approved actions using a simulated retail backend.

## Technical Direction

- Meta multimodal models for image and instruction understanding
- Agent orchestration and structured tool calling
- Human approval and action validation
- Serverless inference and image processing
- Synthetic data and mock retail APIs

## Project Scope

This is an independent hackathon prototype, started on October 27, 2026.

It uses synthetic demonstration data and a standalone simulated commerce backend. No proprietary platform source code, confidential business information, or real customer data is included.
